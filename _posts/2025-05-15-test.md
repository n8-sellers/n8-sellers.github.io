# How to Set Up GitHub Pages

GitHub Pages is a convenient way to host websites directly from your GitHub repository. This post will walk you through how to set up your own GitHub Pages site with Jekyll.

## What is GitHub Pages?

GitHub Pages is a static site hosting service that takes HTML, CSS, and JavaScript files directly from a repository on GitHub, optionally runs the files through a build process, and publishes a website.

## Setting Up GitHub Pages with Jekyll

### Step 1: Create a Repository

1. Go to [GitHub](https://github.com) and sign in
2. Click the "+" icon in the upper right corner and select "New repository"
3. Name your repository `username.github.io`, replacing "username" with your GitHub username
4. Set the repository to public
5. Initialize the repository with a README

### Step 2: Enable GitHub Pages

1. Go to your repository's settings
2. Scroll down to the "GitHub Pages" section
3. Under "Source", select "main branch"
4. Click "Save"

### Step 3: Choose a Theme

1. In your repository's GitHub Pages settings, click "Choose a theme"
2. Select a theme you like
3. Click "Select theme"

### Step 4: Configure Your Site

Create or edit `_config.yml` file with basic site information:

```yaml
title: "Your Site Title"
description: "Your site description"
remote_theme: pages-themes/minimal@v0.2.0
plugins:
- jekyll-remote-theme
```

### Step 5: Create Content

1. Create an `index.md` file for your homepage
2. Create posts in the `_posts` directory with the filename format: `YYYY-MM-DD-title.md`

### Step 6: View Your Site

Your site will be available at `https://username.github.io`

## Using the Minimal Theme

The Minimal theme is a clean, lightweight Jekyll theme for GitHub Pages. Key features:

1. Simple, clean design focused on readability
2. Responsive layout that works well on various devices
3. Header with logo and navigation options
4. Easily customizable

## Next Steps

To further customize your site:

1. Add more pages by creating additional markdown files
2. Customize your theme by overriding theme files in your repository
3. Add custom CSS by creating a `assets/css/style.scss` file
4. Set up a custom domain for your GitHub Pages site

Happy blogging!
