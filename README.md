# NetLog

A GitHub Pages blog exploring network engineering concepts, tools, and best practices.

This site is built with [GitHub Pages](https://pages.github.com/) using the [Minimal theme](https://github.com/pages-themes/minimal).

Visit the live site at: https://n8-sellers.github.io

## Local Development

To run this site locally:

1. Install Ruby and Bundler
2. Run `bundle install` to install dependencies
3. Run `bundle exec jekyll serve` to start the local server
4. Visit `http://localhost:4000` to view the site
